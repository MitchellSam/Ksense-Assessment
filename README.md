# Ksense | Take Home Assessment

## Instructions:
* Download the repo
  * https://github.com/MitchellSam/Ksense-Assessment
* Install the current stable LTS release of Node
  * Install curl if you don't already have it.
    * `sudo apt-get install curl`
  * Use curl to install the Node Version Manager
    * `curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/master/install.sh | bash`
  * Use nvm to install Node.
    * `nvm install --lts`
* Install node modules
  * `npm install`
* Run the code
  * `node main.js`
